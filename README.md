# 418_ The Daily Brew

**Standups, freshly randomized.**

Open `index.html` in Chrome. Alternatively, run `python3 -m http.server 8000` from this directory and visit `http://localhost:8000`. No dependencies or build step.

1. Click **Manage teammates** and enter the team.
2. Choose any of the five flavors on the terminal-style landing page.
3. Click **Start Brewing** to enter the themed presentation screen.
4. Use Reveal, Skip, Undo, and Start a fresh standup as needed.
5. Use **Brew setup** to return to the landing page without losing the current session.

The house style uses warm charcoal, cream, and tea green, for setup and the shared brand. All five flavors are available every day: The Headliner (entrances), The Dad Blend (jokes), The Champion’s Cup (awards), Déjà Brew (throwbacks), and The Mystic Blend (fortunes). Each keeps its own stage and original response collection, including the Mystic Blend’s animated crystal ball and starry purple backdrop. New visitors start with The Mystic Blend; saved selections and sessions are retained. A completed standup closes with “204 NO CONTENT — The pot is empty. All updates served.” Team members and progress persist in localStorage. The existing storage key is retained to preserve rosters from Standup Shuffle. For Google Meet, share the Chrome tab with tab audio enabled if you want sound effects.

Files: `index.html`, `css/styles.css`, `js/app.js`.
